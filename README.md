# SSIAP-1

## QCU TFP APS

Entraînement QCU (questionnaire à choix unique) pour le **TFP APS** (Titre à finalité professionnelle — Agent de prévention et de sécurité).

Le fichier [`qcu-tfp-aps.html`](qcu-tfp-aps.html) est une page web autonome : il suffit de l'ouvrir dans un navigateur, aucune installation n'est nécessaire.

### Contenu

Les thèmes sont regroupés par UV, dans des sections dépliables :

- **UV02 — Environnement juridique** : Principes de la République, Code pénal, Livre VI · CNAPS · Carte pro, Code de déontologie, Respect des libertés publiques, Conditions d'appréhension
- **UV05 — Incendie**
- **UV06 — Métiers & appréhension** : Filières métiers, Modalités d'appréhension (en exercice)

### Fonctionnalités

- Choix des thèmes et du nombre de questions
- Correction immédiate avec explication après chaque réponse
- Option de mélange de l'ordre des réponses
- Résultat final : score, seuil de réussite, détail par thème et correction complète
- Thème clair / sombre, adapté mobile

Questions tirées des fiches de révision CFPS.
