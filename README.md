# SSIAP-1

## QCU TFP APS

Entraînement QCU (questionnaire à choix unique) pour le **TFP APS** (Titre à finalité professionnelle — Agent de prévention et de sécurité).

Le fichier [`qcu-tfp-aps.html`](qcu-tfp-aps.html) est une page web autonome : il suffit de l'ouvrir dans un navigateur, aucune installation n'est nécessaire.

### Contenu

Les thèmes sont regroupés par UV, dans des sections dépliables :

- **UV02 — Environnement juridique** : Principes de la République, Code pénal, Livre VI · CNAPS · Carte pro, Code de déontologie, Respect des libertés publiques, Conditions d'appréhension
- **UV04 — Module stratégique (transmission)**
- **UV05 — Incendie**
- **UV06 — Métiers & appréhension** : Filières métiers, Modalités d'appréhension
- **UV07 — Risques terroristes & secourir**
- **UV08 — Accueil, communication & contrôle d'accès**
- **UV09 — Palpation & contrôle des sacs**
- **UV10 — Télésurveillance & vidéoprotection**
- **UV11 — Gestion des risques** : Risque électrique, Gestion des alarmes & SSI
- **UV14 — Module industriel** : Risques professionnels & prévention, Risque industriel majeur, Produits dangereux / ATEX / TMD

### Fonctionnalités

- **Révision** par thèmes choisis (toutes les questions des thèmes sélectionnés)
- **Examen blanc** : nombre de questions par UV conforme à l'examen, tirage aléatoire
- **Dates & lois** : page de révision des articles (CPP 73, 53, 55…) et dates clés, avec échelle de priorités
- **Historique** : score et nombre d'erreurs conservés par appareil (local)
- Correction immédiate avec explication après chaque réponse
- Option de mélange de l'ordre des réponses
- Résultat final : score, seuil de réussite, détail par thème et correction complète
- Thème clair / sombre, adapté mobile

Questions tirées des fiches de révision.
